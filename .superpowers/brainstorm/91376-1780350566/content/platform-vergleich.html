Plattform-Auswahl: B vs. C

Welche Basis passt am besten für die Grubenberechnungssoftware?

Option B — Lokale Web-App
HTML + JavaScript + SQLite (via bessqlite3)
✅ Vorteile
  • Sofort startbar — start.command Doppelklick
  • Kein Build-Prozess, kein Installer
  • Einfache Aktualisierungen
  • Kleine Dateigröße (~100 KB App)
  • Schnelle Entwicklung
⚠️ Nachteile
  • Läuft im Browser (kein eigenes Fenster)
  • Kein App-Icon im Dock
  • Node.js muss installiert sein
💡 Perfekt wenn: schnelle Lösung, einfache Wartung, kein IT-Aufwand
⚡ Schnell & Leicht
Option C — Tauri Desktop-App
Tauri (Rust) + Vue/React + SQLite (eingebaut)
✅ Vorteile
  • Echtes App-Fenster, eigenes Icon
  • Keine Abhängigkeiten beim Endnutzer
  • Sehr klein (~5–10 MB .app-Datei)
  • Professionellstes Ergebnis
  • Systembenachrichtigungen, Tray-Icon
⚠️ Nachteile
  • Rust muss installiert sein (für Build)
  • Erster Build dauert ~5 Minuten
  • Etwas komplexere Entwicklung
💡 Perfekt wenn: professionelles Werkzeug, sieht aus wie eine echte App
🏆 Professionell & Standalone
🎯 Meine Empfehlung

Für ein professionelles Betriebswerkzeug im Bau-Bereich empfehle ich Option C (Tauri). Es sieht aus wie eine echte Desktop-App, hat ein eigenes Fenster und Icon, und die finale .app-Datei kann einfach per Doppelklick gestartet werden — ohne Browser, ohne Abhängigkeiten. Der einmalige Build-Aufwand lohnt sich für den professionellen Eindruck.
